# Sample DXF files

Real files, written by other programs, so the reader and writer are tested on more than what we imagine a DXF to be. They come from the
test data and examples of [ezdxf](https://github.com/mozman/ezdxf), under its MIT licence (`LICENSE.ezdxf`), unchanged. They're only read by the tests.

The tests assume nothing about any one of them except that a text one comes back byte for byte (`tests/test_dxf.py`).
